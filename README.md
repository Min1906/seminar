Website interaktif canvas **e-Portofolio Seminar Kelulusan Program Pendidikan Profesi Guru (PPG) Prajabatan** Bidang Studi **Pendidikan Informatika**.

🌐 **Live Demo (Vercel)**: [https://temporary-brisk-platinum-ez3wy0g.vercel.app](https://temporary-brisk-platinum-ez3wy0g.vercel.app)

---

## 🌟 Fitur Utama

1. **Visi & Filosofi Pendidikan Pendidik**: Menampilkan komitmen transformatif, pemikiran Ki Hadjar Dewantara, dan profil guru profesional era digital.
2. **Ruang Refleksi Kritis Mata Kuliah (Model Gibbs & 4F)**: Dokumentasi reflektif menyeluruh dari mata kuliah inti, selektif, dan elektif PPG.
3. **Galeri Karya & Inovasi Pembelajaran Digital**: Showcase media pembelajaran interaktif, modul komputasi, dan platform asesmen gamifikasi kelas.
4. **Rencana Tindak Lanjut (RTL) Guru Profesional**: Matriks kerja strategis dan rencana pengembangan keprofesian berkelanjutan (PKB).
5. **Gudang Arsip & Bukti Unggah (IndexedDB Engine)**:
   - Sistem penyimpanan berkas lokal **IndexedDB** berkapasitas besar tanpa batasan kuota 5MB.
   - Fitur **Unggah, Edit (Ganti Berkas), Hapus, Pratinjau (PDF & Gambar), serta Unduh Berkas Asli**.
6. **Presenter HUD Mode**: Mode navigasi slide khusus untuk presentasi seminar di hadapan Dosen Pembimbing dan Guru Pamong.
7. **Tema Dinamis (Dark / Light Mode)** & Desain Responsif Premium.

---

## 🛠️ Teknologi & Stack

- **HTML5 & Semantic Structure**
- **Vanilla CSS3** (Custom Properties, Glassmorphism, 3D Tilt, Modern Grid/Flexbox)
- **Modern JavaScript (ES6+)**
- **IndexedDB API** (Persistent Binary File Storage)
- **Vercel** (Cloud Edge Hosting)
